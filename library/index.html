Mini Library System

A Python project by Chandan Kumar

About this project

The Mini Library System is a library manager I wrote in Python. It keeps track of books and how many copies of each one are on the shelf. The box further down is a JavaScript copy of the same idea, so you can try it right here in the browser.

What it does

  • Adds a book with a title, an author and a number of copies. If the title is already on the shelf (capital letters are ignored), the copies are added to that book instead of making a duplicate.
  • Lets you borrow a book. One copy leaves the shelf, and the count can never go below zero.
  • Lets you return a book. One copy goes back on the shelf.
  • Saves the whole library to a JSON file and a CSV file.

The classes I wrote

The files it saves

  • library.json holds the whole library with every detail, ready to be loaded back into Python.
  • library.csv holds one row per book and opens in Excel.
